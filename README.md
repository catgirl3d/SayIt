# SayIt

Голосове введення з відкритим кодом для Windows. Натисніть гарячу клавішу та говоріть — SayIt розпізнає мовлення, очищує та редагує текст за допомогою AI і вставляє готовий текст прямо туди, де стоїть курсор.

## Особливості форку

Цей проєкт — підтримуваний форк [crosswk/SayIt](https://github.com/crosswk/SayIt). Завантажити інсталятор для Windows можна в розділі [Releases](https://github.com/catgirl3d/SayIt/releases/latest), а повний перелік змін та покращень — у [журналі оновлень](CHANGELOG.md); український переклад — [CHANGELOG.uk.md](CHANGELOG.uk.md).

**Мови диктування:** SayIt підтримує англійську, українську, російську та китайську. Вбудовані промпти для AI-обробки доступні англійською та українською; мову промптів можна вибрати в налаштуваннях AI. За замовчуванням мова промптів відповідає мові інтерфейсу. Мову розпізнавання (ASR) можна вибрати окремо — достатньо обрати модель, що підтримує потрібну мову.

## Чому SayIt?

Набір тексту на клавіатурі часто залишається найповільнішим етапом взаємодії з комп'ютером та AI. SayIt перетворює мовлення на готовий текст і водночас залишає вам повний контроль над ключовими налаштуваннями:

- **Голосове введення всюди** — диктуйте в текстових редакторах, месенджерах, браузерах і будь-яких інших застосунках для Windows.
- **Субтитри комп'ютера з живим перекладом** — вмикайте субтитри та переклад наживо для відео, дзвінків (Zoom, Discord) і будь-яких застосунків завдяки нативному захопленню звуку Windows (WASAPI loopback) без додаткових драйверів чи програм. Підтримуються наскрізний клікабельний оверлей поверх усіх вікон, режим подвійних субтитрів (оригінал і переклад) та незалежне налаштування мов.
- **Гнучка AI-обробка** — прибирайте слова-паразити, виправляйте огріхи розпізнавання, структуруйте думки або зберігайте дослівну транскрипцію. Кожен системний промпт можна адаптувати під себе.
- **Контекстне введення** (за замовчуванням вимкнено) — зчитує текст навколо курсора, щоб нові речення відповідали тону та термінології вашого документа. Якщо перед диктуванням виділити фрагмент тексту, сказане можна використати як інструкцію: перекласти, скоротити, переписати або підготувати відповідь. Результат автоматично замінить виділений фрагмент. Текст із полів паролів не зчитується. Типово редагування виділеного тексту використовує поточну AI-модель; окрему збережену модель можна вибрати в налаштуваннях → «AI-обробка» → «Врахування контексту».
- **Гнучке розпізнавання мовлення** — підключайте хмарні ASR-сервіси, запускайте локальні GGUF-моделі на своєму GPU або під'єднуйтеся до бекенду SayIt, який запускаєте самі чи якому довіряєте.
- **Інтерфейс українською та англійською** — застосунок автоматично використовує мову системи, мову інтерфейсу можна будь-коли змінити в налаштуваннях.
- **Словник термінів (hotwords) і правила для застосунків** — покращуйте розпізнавання імен, назв та професійної лексики, а також автоматично змінюйте правила AI-обробки залежно від активного застосунку.
- **Зручний оверлей** — компактний плаваючий віджет з індикатором рівня звуку показує стан запису й таймер, а також може виводити субтитри наживо під час мовлення.
- **Прозорість обробки даних** — застосунок чітко показує активний режим і те, куди саме спрямовуються аудіо та текст.
- **Локальна історія та діагностика** — переглядайте записи, повторно запускайте розпізнавання та формуйте діагностичні звіти, щоб швидше знаходити й усувати проблеми.

## Режими роботи

| Режим | Для чого підходить | Обробка даних |
| --- | --- | --- |
| **Локальний режим** | Повна приватність і робота без інтернету | Розпізнавання відбувається повністю на вашому ПК. Якщо вимкнути AI-обробку, жодні дані не залишають пристрій. |
| **Хмарний API** | Швидке розпізнавання без локальних моделей | Застосунок напряму звертається до вибраних провайдерів ASR та AI без проміжних серверів SayIt. |
| **Власний сервер** | Робота в команді або керована інфраструктура | Аудіо обробляється на бекенді SayIt, який ви запускаєте або якому довіряєте. |

У каталозі локальних моделей доступно 15 оптимізованих GGUF-моделей із підтримкою GPU-прискорення: Parakeet Unified EN, Parakeet TDT v3 та 1.1B, SenseVoice Small, Fun-ASR Nano та MLT Nano, Nemotron 3.5 ASR (40 мов), GigaAM v3 (RNN-T і CTC), Qwen3-ASR 0.6B та дві квантовані версії 1.7B, а також Whisper Small, Large v3 і Large v3 Turbo. Для хмарного розпізнавання підтримуються Doubao, Qwen, Xiaomi MiMo та Groq Whisper; AI-обробка працює з DeepSeek, Qwen, Doubao, Groq, MiMo, Ollama та будь-якими OpenAI-сумісними API.

## Початок роботи

1. Завантажте останню версію [інсталятора для Windows](https://github.com/catgirl3d/SayIt/releases/latest).
2. Відкрийте SayIt і виберіть голосовий рушій — локальний режим (завантажте модель), хмарний API (власний ключ) або власний сервер. Майстер першого запуску допоможе з налаштуванням.
3. Натисніть гарячу клавішу в будь-якому застосунку та почніть говорити. За замовчуванням перше натискання вмикає запис, а повторне — зупиняє його; також можна налаштувати режим диктування з утриманням клавіші.

API-ключі хмарних провайдерів вводяться в налаштуваннях застосунку, а посилання на консоль кожного сервісу розташоване поруч із полем його ключа.

## Власний сервер (Self-hosting)

Бекенд поєднує FastAPI, потокове передавання через WebSocket, Qwen3-ASR та необов'язкову модель AI-обробки через OpenAI-сумісний API. Рекомендований спосіб розгортання — Docker Compose.

```bash
git clone https://github.com/catgirl3d/SayIt.git
cd SayIt/server
cp config.example.yaml config.yaml
cp .env.example .env
# Вкажіть налаштування провайдерів і параметри розгортання в .env/config.yaml
docker compose up -d --build
```

Докладніше про налаштування, розгортання, безпеку та API читайте в [посібнику з налаштування сервера](server/README.md).

## Розробка

### Десктопний клієнт

```bash
cd client
npm install
npm run tauri dev
```

Вимоги: Node.js 18+, Rust 1.75+, CMake 3.20+ та Vulkan SDK. Перша компіляція нативного рушія C++ займає близько 20 хвилин, а завдяки кешу наступні збірки проходять значно швидше.

Якщо у вас встановлена не англомовна версія Windows, перед запуском збірки встановіть змінну середовища `CL=/utf-8`, щоб компілятор MSVC коректно зчитував файли вихідного коду в кодуванні UTF-8.

### Сервер

```bash
cd server
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
cd backend
uvicorn app.main:app --port 8000
```

Вимоги: Python 3.10+ та відеокарта NVIDIA з CUDA для запуску моделей на GPU.
