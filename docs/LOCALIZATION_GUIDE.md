# Гайд локалізації форку SayIt

Лексикон і стильовий довідник для рядків `en`/`uk`. Кожне рішення щодо термінології чи
стилю, ухвалене на рев'ю, живе тут; якщо гайд і рядок розходяться — або рядок
неправильний, або гайд треба явно оновити в тому ж зміні.

## Де живуть переклади

- `client/src/i18n/locales/en.json` — джерельні рядки; еталон змісту.
- `client/src/i18n/locales/uk.json` — українська; мусить мати ті самі пласкі ключі й ті
  самі `{плейсхолдери}`, що й `en.json`.
- Редагуємо **лише значення**: ніколи не змінюємо ключі, плейсхолдери, `**маркери
  розмітки**` чи `\n` з боку української локалі.

## Ґейти (запускати перед комітом змін локалі)

- `npm run i18n:check` — строгий ґейт: жодного зашитого китайського в `client/src`,
  жодного CJK в en/uk, паритет ключів en↔uk, паритет плейсхолдерів для кожного ключа.
- `npm run test:scripts` — тести скриптів, включно з тестами самого ґейта.
- `npm test` — набір vitest клієнта.

CI (`ci-frontend.yml`) запускає всі три.

| copy (кнопки, діалоги) | **Копіювати** | «Копіювати текст», «Копіювати посилання»; у реченнях «Скопіюйте…» доречно, але ярлика «Скопіювати» немає |
| dismiss (сповіщення, підказки) | **Закрити** | |
| upload | **вивантаження / вивантажувати** | download лишається «завантаження / завантажувати» — не змішувати пару |
| backup (іменник) | **резервна копія** | «Backed up» → «Резервну копію створено» |

## Числа та плейсхолдери

Значення за плейсхолдерами типу `{count}` можуть бути 1–4, а звичайний рядок не
відмінюється. **Ніколи не ставте відмінюваний іменник одразу після числа.** Два безпечні
шаблони:

1. Ярлик спочатку, число в кінці: «Термінів у словнику: **{count}**», «Копій у сховищі:
   {count}», «Конфігурацій збережено: {count}».
2. Невідмінювані скорочення: «{count} хв», «{count} с», «{count} симв.», «{count} мс».

Погано: «У вас {count} термінів» — рендериться як «1 термінів».

Набір плейсхолдерів у ключі незмінний і має збігатися з `en.json` (ґейт перевіряє це
механічно).

## Стиль і правопис

- Регістр: всюди офіційне «ви»; імператив множини (`-іть`: «Натисніть», «Введіть»).
  Форм «ти» немає.
- Апостроф: тільки прямий `'` (U+0027) — «комп'ютері», «з'єднання». U+2019 не вживається.
- Многоточчя: один символ «…»; ASCII `...` не вживається ні в uk, ні в en.
- Лапки «…»; тире — з пробілами навколо.
- Зберігайте `**жирні**` маркери та `\n` точно як в `en.json`.

## Джерела для звірки

- **Офіційна українська локаль Discord** — основне джерело для термінології (знято
  2026-10-14 з десктопного клієнта; за потреби — перезняти з рантайму клієнта).
- **Український правопис (2019)** — питання правопису й типографіки.
- **Звіти аудитів сесії** (термінологія, семантика, граматика, полірування) —
  робочі звіти поза репозиторієм.

## Відкриті пункти

Наразі відкритих пунктів немає: усі рішення з аудитів (термінологія, семантика,
граматика, полірування) застосовано. Якщо під час роботи виникає сумнів щодо рядка —
фіксуйте його тут, доки не буде ухвалено остаточне рішення.

## Оновлення гайда

Будь-яке ухвалене рішення щодо термінології чи стилю має потрапити сюди в тому ж зміні,
що й рядки. Рев'ю та AI-агенти, працюючи з локаллю, спершу читають цей файл.
